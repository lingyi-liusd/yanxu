# 研序 v2 预览 · 2026.10.05-v2.preview.8

一个研序产品：项目、评审、观察；安装包内沿用同一本机核心和数据服务。

- 评审：先保存问题、约束和选取材料；开始前选择一个执行器并确认输入。一次评审基线为一轮、一次配额。简报可修订、定位引用、导出；已采纳版本保留，不被后续编辑覆盖。
- 观察：围绕问题登记来源。支持 RSS、Atom、JSON Feed 条目解析及网页/文本比较；显示成功覆盖、失败、过期与未检查。来源包只登记来源，默认暂停读取与推送。
- 接续：人工采纳可保存到个人空间或研序项目；保留简报版本、材料哈希和复核条件。来源变化只提示待复核，不自动推翻判断或启动模型。
- Mac 菜单提供“打开评审专注窗口”和“打开观察专注窗口”。旧 `/apps/discussion/`、`/apps/radar/` 路由仍可使用。
- 评审 → 执行器设置 → 登记外部 Agent，可取得当前空间的 READ 或 PROPOSE 连接。默认只允许读取记录和提出建议；先预检再登记，不启动模型或授予文件读取。配置不代表在线，需客户端实际握手。令牌默认隐藏，可自行显示后手动复制；关闭回执清空该字段。

预览版用独立 `ResearchDeskV2Preview` 数据目录和独立 Codex 登录目录，端口 18765。与旧研序实例端口冲突时会提示退出原实例，不能自动停止不属于本包的服务。关闭最后一个窗口默认退出并停止本包核心；菜单退出也停止核心。后台运行沿用明确开关，休眠/退出期间不保证来源覆盖。

本包复用已发布 beta.16 的校验过的运行依赖；源代码、原生宿主和清单重新生成并测试。没有用户数据、账号凭据或自动执行授权。没有发布到 GitHub，也没有替换已安装的应用。macOS 为本地 ad-hoc 签名，未公证；Windows 的运行行为需要真实机器验收。

软件测试、原生运行、真实来源、真实模型和用户收益分别记录。源码测试与合成回复不代表真实模型质量或用户价值。若公开来源解析到非公开地址，观察会保留读取失败，不能写成“没有变化”。引用只验证材料 ID 和行号，不验证论断真假。

调用配额在本机保存为单调消耗记录。旧备份恢复不会清除本机最新消耗，不自动重放已中断的评审。外部执行器使用自己的配额时，本产品只记录接受的回复，不能观察其真实计费。复制整个数据库到更早副本或删除数据库不属于这种恢复保证。

先用非关键材料试用。实际已验结果以同目录验收回执和项目交接为准。

本版抽出前端接口客户端与项目状态模块；页面切换的晚到响应不能覆盖当前项目，写入仍先预览并核对版本。不增加自动模型调用。

评审草稿可明确勾选要带入的项目任务、判断和结果，默认不选；复核原判断时自动包含该判断。只有选定记录和项目信息变化才使新评审上下文过期；旧评审保持原范围。

原评审内可“使用历史快照”建立新评审：明确勾选 1–12 份快照并填写理由，保存原对象/上下文版本与已耗配额；新草稿不自动运行。当前项目信息与本次选定当前记录继续校验。跨项目采纳使用目标项目对象版本，旧客户端继续沿用全目标上下文门禁。

执行结果若能通过已采纳任务与原评审明确关联已有观察来源，会在观察模式提出规则复核候选。可维持原规则，或编辑关注问题/关键词/检查间隔后确认；保存理由与原结果版本，不改原判断/结果、不新增来源，不启用自动检查或推送。页面最多展示50个待处理候选并明确总数，每来源保留最多50条处理收据，达到上限保留历史并拒绝继续追加。

Today 在读取最新项目列表后确定本次项目范围；没有正式项目时显示开始页，不读取隐含的个人空间。返回的项目与选择不符时停止显示该结果并提示重新读取。
