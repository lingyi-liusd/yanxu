基线：桌面 2026.10.03-beta.16。运行源码与本版摘要核对；公开仓库使用明确文件清单和独立初始历史。真实项目、账号、令牌、数据库、缓存与私有开发记录不进入仓库。

验证入口：docs/VALIDATION.md 与 docs/receipts/。本次模型调用为零，科研计算为零，不改真实项目记录。桌面包保持原字节，本版原生 GUI、Windows 真机和用户收益仍未验证。

后续工作：优先处理陌生人的首次启动、Windows 实机、长期稳定性与高级文案。没有实质变更不重复追加审计，也不重跑未受影响的模型或科学实验。
